## 🎮 About the Project

MathBattle is a lightweight, installable web game designed to make mental math practice fun and competitive. Two players face off in real time, answering addition, subtraction, and multiplication questions on their own keypad — every correct answer pulls a virtual rope toward their side, with the first team to drag it to their goal winning the match.

Built entirely with vanilla HTML, CSS, and JavaScript — no frameworks, no backend, no build step — and packaged as an installable Progressive Web App (PWA).

## ✨ Features

- Two-player local multiplayer with independent keypads
- Addition, subtraction, and multiplication question modes
- Animated rope-pull physics, sound effects, and confetti celebration on win
- Friendly welcome screen introducing the game's purpose
- Editable team names, with a "Change Teams" option mid-game
- Installable as a desktop/mobile app (PWA) via the "Install App" button
- 100% static — runs entirely client-side

## 🛠️ Tech Stack

- **HTML5** — structure and markup
- **CSS3** — styling, layout, and animations
- **JavaScript (Vanilla)** — game logic, scoring, and PWA setup
- **Service Worker + Web App Manifest** — offline support and installability
